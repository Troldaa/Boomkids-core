# Boomkids Core

Moderní interní portál pro Boomkids.

## Funkce

- Přihlašovací obrazovka připravená pro napojení na Supabase/Firebase/NextAuth
- Dashboard podle rolí
- Kategorie: Marketing, Příměstské tábory, Pohybové aktivity, Finance, Teplobook Boomkids
- Základ pro interní wiki, dokumenty, finance a provozní přehledy

## Spuštění

```bash
npm install
npm run dev
```

Aplikace poběží na `http://localhost:3000`.

## Doporučené další kroky

1. Napojit autentizaci.
2. Přidat databázi a role uživatelů.
3. Napojit Google Drive/Calendar.
4. Rozšířit Teplobook o editor článků a vyhledávání.
